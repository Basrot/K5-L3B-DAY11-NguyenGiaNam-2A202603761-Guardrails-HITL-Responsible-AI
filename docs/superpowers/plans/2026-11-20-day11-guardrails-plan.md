## Review Focus
- Unicode zero-width injection in trusted-looking email text: must be caught without blocking benign external summaries (CP2).
- Ordinary banking language without narrow keywords: topic classifier should permit useful bank requests (CP2).
- Sensitive values adjacent to punctuation or Vietnamese labels: redact values and preserve safe text (CP2).
- Requests to an allowed hostname over HTTP, a deceptive suffix domain, or with credentials in payload: reject (CP3).
- Rate-window boundary and independent users: enforce per-user sliding windows (CP3).
